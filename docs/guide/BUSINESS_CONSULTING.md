## 1. 사업자 등록 기초

### 1.1 사업자란?

**사업자**란 영리 목적으로 독립적으로 재화 또는 용역을 공급하는 자를 말합니다. 앱을 통해 수익(광고, 인앱결제, 구독 등)을 창출하려면 **반드시 사업자 등록이 필요**합니다.

### 1.2 사업자를 꼭 내야 하나요?

| 상황 | 사업자 등록 필요 여부 |
|------|---------------------|
| 무료 앱만 운영 (수익 없음) | ❌ 불필요 |
| 광고 수익 발생 | ✅ 필요 |
| 인앱결제/구독 수익 발생 | ✅ 필요 |
| 정부 지원금 신청 | ✅ 필요 |
| 투자 유치 | ✅ 필요 (법인 권장) |

> **결론**: 밍그르르를 통해 **수익을 창출하거나 정부 지원을 받으려면 사업자 등록이 필수**입니다.

### 1.3 사업자 등록 절차

#### 📍 개인사업자 등록 방법

**방법 1: 관할 세무서 방문**
1. 사업장 관할 세무서 방문
2. 사업자등록 신청서 작성
3. 필요 서류 제출
4. 3~5일 내 사업자등록증 발급

**방법 2: 홈택스 온라인 등록 (권장)**
1. [홈택스](https://www.hometax.go.kr) 접속
2. 공동인증서 로그인
3. 신청/제출 → 사업자등록 신청
4. 정보 입력 및 서류 첨부
5. 1~3일 내 발급

#### 📄 필요 서류

| 서류 | 필수 여부 | 비고 |
|-----|:--------:|------|
| 사업자등록 신청서 | ✅ | 홈택스에서 작성 |
| 신분증 사본 | ✅ | 주민등록증/운전면허증 |
| 임대차계약서 | △ | 자택이면 불필요 |
| 사업허가증 | △ | 인허가 업종만 해당 |

> **💡 Tip**: IT/앱 서비스업은 별도 인허가 없이 등록 가능합니다.

### 1.4 업종 코드 (앱 서비스)

## 2. 개인사업자 vs 법인 비교

### 2.1 한눈에 비교

| 구분 | 개인사업자 | 법인사업자 |
|------|-----------|-----------|
| **설립 비용** | 무료 | 30~50만원 |
| **설립 기간** | 1~3일 | 7~14일 |
| **세율** | 6~45% (누진) | 9~24% (2026년) |
| **책임 범위** | 무한책임 | 유한책임 |
| **대외 신뢰도** | 낮음 | 높음 |
| **투자 유치** | 어려움 | 용이 |
| **정부지원 유리** | 보통 | 유리 |
| **운영 복잡도** | 간단 | 복잡 |
| **세무 비용** | 월 5~10만원 | 월 15~30만원 |

### 2.2 법적 책임의 차이

```
📌 개인사업자
- 사업주 = 사업체 (동일 인격)
- 사업 부채 → 개인 재산으로 변제 의무 (무한책임)
- 사업 실패 시 개인 파산 위험

📌 법인사업자  
- 법인 ≠ 대표이사 (별개 인격)
- 회사 부채 → 회사 자산으로만 변제 (유한책임)
- 출자금 한도 내에서만 책임
```

### 2.4 언제 법인이 유리한가?

| 상황 | 권장 형태 |
|------|----------|
| 연 매출 5천만원 미만 | 개인사업자 |
| 연 순이익 5천만원 이상 | 법인 전환 검토 |
| 투자 유치 계획 있음 | 법인 (필수) |
| 정부 지원금 적극 활용 | 법인 (유리) |
| 1인 개발, 소규모 운영 | 개인사업자 → 법인 전환 |

### 2.5 💡 밍그르르 추천 전략

```

   - 시장 검증 단계

🎯 2단계: 법인 전환 시점
   - 연 순이익 5천만원 이상 달성
   - 정부 지원금 본격 신청
   - 투자 유치 진행 시
   
🎯 예상 전환 시점: 출시 후 1~2년 내
```

## 3. 세금의 이해

### 3.1 왜 세금을 내야 하나요?

세금은 국가와 지방자치단체가 공공 서비스(도로, 교육, 의료, 치안 등)를 제공하기 위한 재원입니다. 사업으로 수익이 발생하면 그에 대한 세금을 납부할 **법적 의무**가 있습니다.

### 3.2 앱 사업자가 납부하는 세금

| 세금 종류 | 납부 시기 | 대상 | 세율/금액 |
|----------|----------|------|----------|
| **부가가치세** | 1월, 7월 (연 2회) | 매출 발생 시 | 10% |
| **종합소득세** | 5월 (연 1회) | 개인사업자 | 6~45% |
| **법인세** | 3월 (연 1회) | 법인사업자 | 10~25% |
| **지방소득세** | 소득세와 동시 | 모든 사업자 | 소득세의 10% |
| **4대보험** | 매월 | 직원 채용 시 | 약 9% (사업자 부담분) |

### 3.3 부가가치세 과세 유형

| 유형 | 기준 | 세금계산서 | 매입세액공제 |
|------|------|:--------:|:----------:|
| **일반과세자** | 연 매출 1.04억원 이상 | ✅ 발급 가능 | ✅ 전액 공제 |
| **간이과세자** | 연 매출 1.04억원 미만 | ❌ 발급 불가 | △ 일부 공제 |

> **💡 Tip**: 앱 서비스는 초기 매출이 낮으므로 **간이과세자**로 시작 가능

### 3.4 세금 신고 일정 (2026년)

| 월 | 신고/납부 내용 |
|---|--------------|
| 1월 | 부가가치세 확정신고 (7~12월분) |
| 3월 | 법인세 신고 (법인만) |
| 5월 | 종합소득세 신고 (개인사업자) |
| 7월 | 부가가치세 확정신고 (1~6월분) |

### 3.5 절세 팁

1. **비용 증빙 철저히**: 서버비, 개발툴 구독료, 장비 등 모두 경비 처리
2. **청년창업 세액감면**: 최대 5년간 50~100% 감면 (아래 상세 설명)
3. **4대보험료 공제**: 본인 4대보험료 전액 경비 처리
4. **세무사 기장 대행**: 월 10~15만원으로 절세 효과 극대화

### 18.6 스톡옵션 전략

초기 스타트업은 급여 대신 스톡옵션으로 인재 유치 가능

#### 스톡옵션이란?

```
📌 스톡옵션 (주식매수선택권)
= 미래에 정해진 가격으로 회사 주식을 살 수 있는 권리

예시:
- 입사 시 주당 1,000원에 1% 스톡옵션 부여
- 3년 후 회사 가치 100억 → 주당 10,000원
- 스톡옵션 행사 시: (10,000 - 1,000) × 1% = 9,000만원 이익
```

#### 스타트업 스톡옵션 가이드

| 직급 | 일반적인 지분율 | 밍그르르 예상 |
|------|:-------------:|:------------:|
| 공동창업자 | 10~25% | N/A |
| 초기 핵심 멤버 (1~3번) | 1~5% | 2~3% |
| 초기 직원 (4~10번) | 0.5~1% | 0.5~1% |
| 후기 직원 | 0.1~0.5% | 0.1~0.5% |

#### 스톡옵션 vs 급여 밸런스

| 상황 | 급여 | 스톡옵션 |
|------|------|---------|
| **현금 여유 있음** | 시장 수준 | 적게 |
| **현금 부족** | 낮게 (-20~30%) | 많이 |
| **핵심 인재** | 시장 수준 | 많이 |
