# 🐾 꼬순내지수 가이드

> **꼬순내지수**는 MINGRR 앱의 보호자 신뢰도/평판 시스템입니다.  
> 당근마켓의 "매너온도"와 유사한 개념으로, 반려동물 앱에 맞게 "꼬순내지수"라는 이름으로 구현되었습니다.

## 1. 개요

### 1.1 목적

| 목적 | 설명 |
|-----|------|
| **신뢰도 표시** | 보호자의 활동 이력과 평판을 수치화하여 표시 |
| **안전한 거래/만남** | 상대방의 신뢰도를 확인하고 안전한 활동 유도 |
| **커뮤니티 품질 향상** | 좋은 매너를 가진 사용자에게 인센티브 제공 |
| **악성 사용자 필터링** | 노쇼, 신고 등 부정적 행동에 대한 감점 |

### 1.2 하이브리드 방식

꼬순내지수는 **하이브리드 방식**으로 운영됩니다:

| 구분 | 방식 | 설명 |
|-----|------|------|
| **원점수** | 절대 평가 | 0~100점, 활동에 따라 변동 |
| **등급** | 상대 평가 | 백분위 기반, 주기적 조정 |

### 1.3 기본값

- **신규 가입자 기본 점수**: 50점
- **점수 범위**: 0 ~ 100점
- **기본 등급**: 솔솔 (상위 50%)

## 2. 점수 산정 알고리즘

### 2.1 점수 배분 (100점 만점)

| 카테고리 | 배점 | 세부 항목 |
|---------|------|----------|
| **평판 점수** | 40점 | 평균 평점 30점 + 평가 개수 보너스 10점 |
| **활동 점수** | 20점 | 매칭 8점 + 산책 5점 + 거래 5점 + 소모임 2점 |
| **신뢰도 점수** | 20점 | 인증 12점 + 프로필 완성도 5점 + 계정 연령 3점 |
| **커뮤니티 점수** | 10점 | 게시글 3점 + 댓글 3점 + 받은 좋아요 2점 + 최근 이용 2점 |
| **앱 활성도** | 10점 | 접속 빈도 7점 + 응답률 3점 |
| **감점 요소** | -15점 | 신고 이력 + 노쇼 이력 (시간 감쇠 적용) |

## 3. 등급 체계

### 3.1 등급 정의 (백분위 기반)

| 등급 | 백분위 | 기본 점수 | 색상 | 이모지 | 설명 |
|-----|-------|---------|------|-------|------|
| **빅뱅** | 상위 10% | 90점+ | 금색 `#FFD700` | ✨ | 우주 끝까지 퍼지는 향! 레전드 |
| **화산** | 상위 20% | 80점+ | 주황 `#FF9500` | 🌋 | 용암처럼 강렬한 냄새! |
| **뜨끈** | 상위 30% | 70점+ | 빨강 `#FF6B6B` | 🔥 | 뜨끈뜨끈 따끈한 냄새! |
| **솔솔** | 상위 50% | 50점+ | 파랑 `#4A90D9` | 💨 | 은은한 냄새가 솔솔~ |
| **쑥쑥** | 하위 50% | 0점+ | 초록 `#4CAF50` | 🌱 | 냄새가 자라는 중! 더 놀아줘요 |

### 3.2 동적 등급 구간

등급 구간은 **전체 사용자 분포에 따라 주기적으로 조정**됩니다.

```dart
// 등급 구간 업데이트 (100명 이상 유저 시)
static Future<void> updateGradeThresholds() async {
  final scores = await getAllUserScores();
  if (scores.length < 100) return;
  
  scores.sort((a, b) => b.compareTo(a)); // 내림차순
  
  _thresholdBigBang = scores[(scores.length * 0.10).floor()]; // 상위 10%
  _thresholdVolcano = scores[(scores.length * 0.20).floor()]; // 상위 20%
  _thresholdHot = scores[(scores.length * 0.30).floor()];     // 상위 30%
  _thresholdSolsol = scores[(scores.length * 0.50).floor()];  // 상위 50%
}
```

### 3.3 빅뱅 마스터 배지

- **조건**: 상위 10% (빅뱅 등급)
- **표시**: 금색 발바닥 배지 + 반짝임 효과
- **특전**: 프로필 테두리 금색 글로우

## 4. 감점 시스템

### 4.1 설계 철학

기존 영구 감점 방식의 문제점을 해결하기 위해 **회복 가능한 하이브리드 방식**을 도입했습니다.

| 기존 문제 | 해결책 |
|---------|-------|
| 한 번 감점 → 영원히 100점 불가 | 시간 감쇠로 회복 가능 |
| 시간이 지나도 감점 유지 | 6개월 후 감점 만료 |
| 개선 의지 무시 | 긍정 평가로 감점 상쇄 |

### 4.2 신고 감점 (최대 -10점)

#### 시간 감쇠율

| 계정 연령 | 감쇠율 | 예시 (신고 2회) |
|---------|-------|---------------|
| 30일 미만 | 100% | -6점 |
| 30~180일 | 80% | -4.8점 |
| 180일 이상 | 60% | -3.6점 |

#### 신고 횟수별 감점

| 신고 횟수 | 기본 감점 |
|---------|----------|
| 1회 | -3점 |
| 2회 | -6점 |
| 3회 이상 | -10점 |

### 4.3 노쇼 감점 (최대 -8점)

| 기간 | 감점 | 설명 |
|-----|-----|-----|
| 최근 90일 | 1회당 -2점 | 100% 반영 |
| 90~180일 | 1회당 -1점 | 50% 감쇠 |
| 180일 이상 | 0점 | **만료 (반영 안 함)** |

### 4.4 선행 상쇄 (최대 +5점 회복)

```
긍정 평가(4점 이상) 10개당 +1점 회복
감점의 최대 30%까지만 상쇄 가능
```

**이유**: 완전 상쇄 시 악성 유저가 평가 조작으로 악용 가능

### 4.5 100점 달성 시나리오

```
[예시: 신고 1회 + 노쇼 2회 유저]

초기 감점: -7점 (93점 최대)
    ↓
6개월 후: -1.8점 (시간 감쇠)
    ↓
긍정 평가 20개 누적: -1.26점 (상쇄)
    ↓
1년 후 + 활발한 활동: 100점 달성 가능 ✅
```

## 5. 평가 시스템

### 5.1 평가 타입

| 타입 | 설명 | 트리거 시점 |
|-----|------|-----------|
| `dating` | 데이팅/산책 후 평가 | 만남 완료 버튼 클릭 |
| `breeding` | 교배 완료 후 평가 | 교배 완료 처리 시 |
| `marketplace` | 마켓 거래 후 평가 | 거래 완료 버튼 클릭 |
| `community` | 소모임 활동 후 평가 | 모임 종료 시 |

### 5.2 활동 결과

| 결과 | 설명 | 점수 영향 |
|-----|------|---------|
| `completed` | 정상 완료 | 평가 점수 반영 |
| `noShow` | 상대방 불참 | 노쇼 감점 |
| `cancelled` | 상호 합의 취소 | 영향 없음 |
| `failed` | 기타 사유로 불발 | 영향 없음 |

### 5.3 평가 태그

#### 긍정 태그 (데이팅)

- 시간 약속을 잘 지켜요
- 친절하고 매너가 좋아요
- 반려동물을 잘 돌봐요
- 대화가 즐거웠어요
- 다음에도 만나고 싶어요

#### 부정 태그 (데이팅)

- 시간 약속을 안 지켜요
- 불친절해요
- 반려동물 관리가 부족해요
- 연락이 안 돼요
- 노쇼했어요

### 5.4 평가 알림 (비공개 방식)

당근마켓 스타일의 **비공개 방식**을 채택했습니다.

**이유:**
1. 솔직한 평가 유도
2. 보복 평가 방지
3. 프라이버시 보호
4. 커뮤니티 분위기 유지

```
[평가 완료 시 상대방 알림]
┌─────────────────────────────────┐
│  🐾 평가가 도착했어요!           │
│                                 │
│  홍길동님이 평가를 남겼어요.     │
│  내 꼬순내지수에 반영됐어요.     │
│                                 │
│  [내 꼬순내지수 보기]            │
└─────────────────────────────────┘

※ 평가 내용(별점, 태그)은 비공개
※ 꼬순내지수 변동만 확인 가능
```

## 6. UI 컴포넌트

### 6.1 점수 표시 위젯

| 위젯 | 용도 | 크기 |
|-----|------|-----|
| `KkosunnaeScoreSmall` | 카드/리스트 | 16px 아이콘 |
| `KkosunnaeScoreMedium` | 프로필/상세 | 20px 아이콘 + 라벨 |
| `KkosunnaeScoreLarge` | 상세 페이지 | 32px 아이콘 + 바 |

### 6.2 사용 예시

```dart
// 작은 크기 (카드/리스트)
KkosunnaeScoreSmall(score: user.kkosunnaeScore)

// 중간 크기 (프로필)
KkosunnaeScoreMedium(
  score: user.kkosunnaeScore,
  onTap: () => showKkosunnaeDetailSheet(context),
)

// 큰 크기 (상세 페이지)
KkosunnaeScoreLarge(score: user.kkosunnaeScore)
```

### 6.3 상세 바텀시트

```dart
// 꼬순내지수 상세 보기
showKkosunnaeDetailSheet(context, userId: targetUserId);
```

**표시 내용:**
- 총점 + 등급
- 카테고리별 점수 바 (시각화)
- 점수 올리는 팁
- 등급 안내

### 6.4 발바닥 아이콘

점수에 따라 발바닥 아이콘이 **아래에서 위로 채워지는** 게이지 형태로 표시됩니다.

```dart
Widget _buildPawIcon(double score, double size) {
  final fillPercent = score / 100;
  
  return Stack(
    children: [
      // 배경 (회색 발바닥)
      Icon(Icons.pets, color: Colors.grey.withOpacity(0.3)),
      // 채워지는 부분
      ClipRect(
        clipper: _PawClipper(fillPercent),
        child: Icon(Icons.pets, color: _getScoreColor(score)),
      ),
    ],
  );
}
```
