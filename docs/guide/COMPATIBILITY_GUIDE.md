# 🐾 반려동물 궁합 가이드

> **궁합 점수**는 MINGRR 앱의 데이팅 기능에서 반려동물 간의 호환성을 수치화한 시스템입니다.  
> 체형, 성격, 거리, 보호자 신뢰도 등 8가지 요소를 종합하여 0~100점으로 표시합니다.

## 1. 개요

### 1.1 목적

| 목적 | 설명 |
|-----|------|
| **호환성 예측** | 반려동물 간의 성격, 체형, 에너지 레벨 호환성 예측 |
| **안전한 만남** | 보호자 신뢰도를 반영하여 안전한 만남 유도 |
| **매칭 효율화** | AI 기반 추천으로 적합한 친구 빠르게 찾기 |
| **사용자 경험** | 직관적인 점수와 등급으로 의사결정 지원 |

### 1.2 점수 범위

- **점수 범위**: 0 ~ 100점
- **표시 형식**: 퍼센트 (%)
- **계산 방식**: 8개 요소의 가중 합계

## 2. 점수 산정 알고리즘

#### B. 같은 특성 매칭 (7%)

## 3. 등급 체계

### 3.1 등급 정의

| 점수 | 등급 | 이모지 | 설명 | 색상 |
|-----|-----|-------|------|------|
| 85~100% | 최고 | 🎉 | 환상의 궁합이에요! | 초록 `#4CAF50` |
| 70~84% | 좋음 | 😊 | 잘 맞는 친구예요! | 연두 `#8BC34A` |
| 55~69% | 보통 | 🙂 | 괜찮은 친구가 될 수 있어요 | 노랑 `#FFC107` |
| 40~54% | 낮음 | 😐 | 조금 맞춰가야 할 수 있어요 | 주황 `#FF9800` |
| 0~39% | 매우 낮음 | 🤔 | 서로 다른 점이 많아요 | 회색 `#9E9E9E` |

### 3.2 등급 결정 로직

```dart
String get grade {
  if (score >= 85) return '최고';
  if (score >= 70) return '좋음';
  if (score >= 55) return '보통';
  if (score >= 40) return '낮음';
  return '매우 낮음';
}
```

## 5. 추천 알고리즘

### 5.1 추천 목록 생성 플로우

```
┌─────────────────────────────────────────────────────────────┐
│                    추천 목록 생성 플로우                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 후보 반려동물 목록 조회                                  │
│     ↓                                                       │
│  2. 각 후보에 대해 궁합 점수 계산                            │
│     ├─ 체형 궁합 (20%)                                      │
│     ├─ 성격 궁합 (20%)                                      │
│     ├─ 거리 (15%)                                           │
│     ├─ 보호자 신뢰도 (15%)                                  │
│     ├─ 인기도 (10%)                                         │
│     ├─ 앱 활성도 (10%)                                      │
│     ├─ 나이 궁합 (5%)                                       │
│     └─ 품종 궁합 (5%)                                       │
│     ↓                                                       │
│  3. 점수순 정렬                                              │
│     ↓                                                       │
│  4. 다양성 확보 (상위 30개 중 랜덤 15개 선택)                │
│     ↓                                                       │
│  5. 최종 추천 목록 반환                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 다양성 확보 로직

```dart
// 상위 30개 중 랜덤으로 15개 선택
if (results.length > maxResults * 2) {
  final topCandidates = results.take(maxResults * 2).toList();
  topCandidates.shuffle(Random());
  return topCandidates.take(maxResults).toList();
}
```

**이유**: 항상 같은 순서로 추천되면 사용자 경험이 단조로워짐

showCompatibilityGuideModal(context);
