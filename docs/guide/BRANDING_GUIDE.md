## 1. 브랜드 철학

### 1.1 브랜드 미션

> **반려동물과 보호자가 함께 행복한 일상을 만들어가는 커뮤니티**

밍그르르는 단순한 반려동물 앱이 아닙니다. 우리는 반려동물과 보호자, 그리고 반려인들 사이의 **따뜻한 연결**을 만들어갑니다.

### 1.2 핵심 가치

| 가치 | 설명 | 앱 내 적용 |
|------|------|-----------|
| **연결 (Connection)** | 반려동물과 보호자, 반려인들 간의 따뜻한 연결 | 데이팅, 소모임, 채팅 |
| **함께 (Together)** | 혼자가 아닌 함께하는 반려생활 | 산책, 커뮤니티, 소모임 |
| **돌봄 (Care)** | 반려동물의 건강과 행복을 위한 세심한 관리 | 건강수첩, 예방접종 알림 |
| **나눔 (Sharing)** | 경험과 물품을 나누는 따뜻한 문화 | 마켓(나눔), 커뮤니티 |
| **신뢰 (Trust)** | 안전하고 믿을 수 있는 커뮤니티 | 위치 인증, 평가 시스템 |

### 1.3 브랜드 스토리

**"밍그르르 (MINGRR)"**는 두 가지 의미가 결합된 이름입니다.

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   MINGRR = Mingle + Grr                                 │
│                                                         │
│   🎉 Mingle (밍글)                                       │
│      "함께 어울리다, 뒹굴거리며 놀다"                     │
│      → 반려동물과 보호자, 반려인들이 함께 어울리는 공간   │
│                                                         │
│   🐕 Grr (그르르)                                        │
│      강아지가 기분 좋을 때 내는 소리                      │
│      → 행복하고 편안한 상태를 표현                       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**브랜드 네이밍 의미:**

| 요소 | 영문 | 의미 | 브랜드 연결 |
|------|------|------|------------|
| **밍** | Mingle | 함께 어울리다, 뒹굴거리며 놀다 | 반려인 커뮤니티, 소모임, 함께하는 산책 |
| **그르르** | Grr | 강아지가 기분 좋을 때 내는 소리 | 행복한 반려생활, 편안한 일상 |

**"밍그르르"**는 반려동물과 보호자가 **함께 뒹굴거리며 행복하게 어울리는** 모습을 담고 있습니다.
마치 강아지가 기분 좋을 때 "그르르" 소리를 내듯, 밍그르르와 함께하는 모든 순간이 행복하길 바라는 마음을 담았습니다.
