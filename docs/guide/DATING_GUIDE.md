# 🐾 데이팅 메뉴 가이드

> **데이팅**은 MINGRR 앱의 핵심 기능으로, 반려동물 간의 만남과 교배를 위한 매칭 서비스입니다.  
> AI 궁합 알고리즘, 거리 기반 검색, 교배찾기 등 다양한 기능을 제공합니다.

## 1. 개요

### 1.1 목적

| 목적 | 설명 |
|-----|------|
| **반려동물 친구 찾기** | AI 궁합 알고리즘으로 잘 맞는 친구 추천 |
| **근처 친구 검색** | 거리 기반으로 가까운 반려동물 찾기 |
| **교배 상대 찾기** | 교배 가능한 반려동물 검색 및 신청 |
| **안전한 만남** | 보호자 인증, 꼬순내지수로 신뢰도 확인 |

### 1.2 주요 기능

| 기능 | 설명 |
|-----|------|
| **AI 궁합 추천** | 8가지 요소 기반 궁합 점수 계산 |
| **거리 필터** | 0.3km ~ 10km 범위 설정 |
| **상세 필터** | 성별, 크기, 나이, 혈통서 필터링 |
| **데이트/교배 신청** | 메시지와 함께 신청 전송 |
| **좋아요** | 관심 있는 반려동물에 좋아요 |
| **매칭** | 상호 신청 시 자동 매칭 + 채팅방 생성 |

## 3. 추천친구 탭

### 3.1 기능

- **AI 궁합 알고리즘** 기반 추천
- 내 대표 반려동물과의 궁합 점수 계산
- 상위 15개 추천 (다양성 확보를 위해 상위 30개 중 랜덤 선택)

### 3.2 카드 정보

| 항목 | 표시 내용 |
|-----|----------|
| **이미지** | 대표 사진 |
| **이름** | 반려동물 이름 |
| **품종/나이** | 품종, 나이 |
| **성별** | 남아/여아 아이콘 |
| **궁합 점수** | 0~100% |
| **거리** | km 단위 |
| **특성** | 성격 태그 (최대 3개) |

### 3.3 궁합 점수 계산

> 상세 내용은 [COMPATIBILITY_GUIDE.md](./COMPATIBILITY_GUIDE.md) 참조

## 7. 신청 시스템

### 7.1 신청 유형

| 유형 | 설명 | 컬렉션 |
|-----|------|-------|
| **데이팅 신청** | 산책/만남 신청 | `dating_requests` |
| **교배 신청** | 교배 신청 | `breeding_requests` |

### 7.2 신청 플로우

```
┌─────────────────────────────────────────────────────────────┐
│                      신청 플로우                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 신청 버튼 클릭                                          │
│     ↓                                                       │
│  2. 내 반려동물 선택 (바텀시트)                              │
│     ↓                                                       │
│  3. 메시지 입력 (선택)                                       │
│     ↓                                                       │
│  4. 신청 전송                                               │
│     ↓                                                       │
│  5. 상대방에게 알림 전송                                     │
│     ↓                                                       │
│  6. 상호 신청 확인 (상대방도 신청했는지)                     │
│     ↓                                                       │
│  7-A. 상호 신청 O → 자동 매칭 + 채팅방 생성                  │
│  7-B. 상호 신청 X → 대기 상태                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 7.3 신청 상태

| 상태 | 설명 |
|-----|------|
| `pending` | 대기 중 |
| `accepted` | 수락됨 |
| `rejected` | 거절됨 |

### 7.4 매칭 성공 시

1. **MatchModel** 생성
2. **ChatRoomModel** 생성 (채팅방)
3. **알림 전송** (상대방에게)

```dart
// 매칭 생성
final match = MatchModel(
  id: matchId,
  userIds: [fromUserId, toUserId],
  petIds: [fromPetId, toPetId],
  chatRoomId: chatRoomId,
  type: 'dating', // 또는 'breeding'
  matchedAt: DateTime.now(),
);
```

### 7.5 알림 유형

| 알림 | 설명 |
|-----|------|
| `datingRequest` | 데이팅 신청 도착 |
| `datingAccepted` | 데이팅 신청 수락 (매칭 성공) |
| `breedingRequest` | 교배 신청 도착 |
| `breedingAccepted` | 교배 신청 수락 (매칭 성공) |

## 8. 데이터 모델

### 8.1 DatingRequestModel

```dart
class DatingRequestModel {
  final String id;
  final String fromUserId;      // 신청자 ID
  final String fromPetId;       // 신청자 반려동물 ID
  final String toUserId;        // 수신자 ID
  final String toPetId;         // 수신자 반려동물 ID
  final DatingRequestStatus status;  // pending/accepted/rejected
  final bool isSuperRequest;    // 슈퍼 신청 여부 (수익화)
  final String? message;        // 신청 메시지
  final DateTime createdAt;
  final DateTime? respondedAt;
}
```

### 8.2 MatchModel

```dart
class MatchModel {
  final String id;
  final List<String> userIds;   // 매칭된 사용자 ID 목록
  final List<String> petIds;    // 매칭된 반려동물 ID 목록
  final String? chatRoomId;     // 생성된 채팅방 ID
  final String type;            // 'dating' 또는 'breeding'
  final int? compatibilityScore; // 궁합 점수
  final DateTime matchedAt;
  final bool isActive;
}
```

### 8.3 BreedingPostModel

class BreedingPostModel {
