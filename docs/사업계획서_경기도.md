## 1. 문제인식(Problem)

### 1-1. 아이템 개발 동기(문제인식) 및 해결방안(필요성)

◦ **개발 동기 – 반려동물 보호자의 분절된 서비스 경험**

  - 국내 반려동물 양육 현황(2024년 기준):
    - 반려동물 양육 가구: 602만 가구(전체 가구의 28.8%)
    - 반려동물 양육 인구: 1,500만 명 이상
    - 출처: 농림축산식품부, KB금융지주경영연구소

  - 이들은 산책, 건강관리, 용품 구매, 다른 반려인과의 교류 등 다양한 니즈를 갖고 있으나, 현재 이를 해결하기 위해 **평균 3~5개의 개별 앱**을 동시에 사용해야 하는 불편을 겪고 있다.

  - 특히 1인 가구 반려인(전체 반려 가구의 약 35%, 약 211만 가구)은 반려동물의 사회화 기회 부족, 건강관리 정보 부재, 주변에 도움을 구할 커뮤니티 부재라는 복합적인 문제에 직면해 있다.

  - 반려동물 간 만남은 보호자의 사회적 네트워크에 의존하거나 공원에서의 우연한 만남에 한정된다. 체형·성격이 맞지 않는 반려동물 간 만남은 공격성, 스트레스 등 부정적 경험으로 이어질 수 있다.

  - 기존 반려동물 커뮤니티 앱은 산책 기록이나 정보 공유에 그치며, '내 반려동물과 잘 맞는 친구 매칭'이라는 핵심 니즈를 해결하지 못하고 있다.

◦ **해결 방안**

  - 반려동물 시장 성장 추이:
    - 2020년: 3.4조원 → 2023년: 4.6조원 → 2025년: 6조원(예상) → 2027년: 10조원 전망
    - 연평균 성장률(CAGR): 10.2%
    - 출처: KB금융지주경영연구소, 한국농촌경제연구원

  - MZ세대를 중심으로 '펫패족(Pet+Family)' 문화가 확산되고 있다. MZ세대 반려인 비중은 전체의 60% 이상(한국펫산업협회).

  - 동물보호법 개정(2024)으로 반려동물 등록 의무화가 강화되면서, 인증 기반 신뢰 커뮤니티에 대한 수요가 증가하고 있다.

  - 기존 앱들의 한계: (1) 단일 기능 집중(산책만, 커뮤니티만)으로 앱 피로도 증가 (2) 보호자 간 신뢰도 검증 수단 부재 (3) 반려동물 특성(성격, 체형)을 고려한 매칭 부재

  - (1) **공원에서 우연히 만남**
    - 한계: 성격·체형 불일치 리스크, 부정적 경험 가능성
    - 해결: 8요소 복합 궁합 매칭 알고리즘으로 과학적 매칭

  - (2) **여러 앱 동시 사용**
    - 한계: 데이터 분산, 앱 피로도, 관리 불편
    - 해결: 6대 기능 통합 원스톱 플랫폼

  - (3) **보호자 신뢰 검증 불가**
    - 한계: 노쇼, 사기 거래 위험, 신원 확인 불가
    - 해결: 꼬순내 지수(5개 영역 100점 신뢰도 시스템)

  - (4) **수기 건강관리**
    - 한계: 기록 누락, 일정 관리 어려움, 체계적 관리 불가
    - 해결: 12개 카테고리 건강수첩 + 예방접종 알림

  - (5) **카페/블로그 정보 검색**
    - 한계: 비체계적, 검증 안 된 정보, 신뢰도 낮음
    - 해결: 소모임 + 인증된 보호자 커뮤니티


### 1-2. 목표시장 분석 및 타겟 설정

◦ **목표시장 분석**

  - 시장 규모 (TAM/SAM/SOM):
    - **TAM (전체 시장)**: 국내 반려동물 산업 전체 – 약 6조원 (2025년, 연평균 성장률 10.2%)
    - **SAM (유효 시장)**: 반려동물 모바일 서비스 시장 – 약 3,000억원 (앱, 온라인 커뮤니티, O2O 서비스)
    - **SOM (수익 가능 시장)**: 수도권 MZ세대 반려견 보호자 대상 커뮤니티 앱 – 약 100억원

  - 시장 지표 (2024년 기준):
    - 반려동물 양육 가구: 602만 가구(전체 가구의 28.8%) - 농림축산식품부
    - 반려동물 양육 인구: 1,500만 명(전체 인구의 29%) - KB금융지주경영연구소
    - 반려견: 760만 마리 / 반려묘: 313만 마리 - 농림축산식품부
    - 시장 규모: 6조원(2025) → 10조원(2027 전망) - 한국농촌경제연구원
    - 시장 성장률: 연평균 10.2%(2020~2027 CAGR) - KB금융지주경영연구소
    - MZ세대 반려인 비중: 60% 이상(20~30대 핵심 타겟) - 한국펫산업협회
    - 1인 가구 반려 비중: 35%(약 211만 가구) - 통계청, KB금융
    - 월평균 양육비: 15만원(사료, 간식, 의료비 등) - KB금융지주경영연구소

  - 경쟁구도 분석:
    - (1) **펫피**(50만+ 다운로드): 산책 기록/포인트 적립/커뮤니티 중심 → 한계: 매칭 기능 없음, 거래 없음, 건강수첩 없음 → **밍그르르**: 데이터 기반 매칭 + 거래 + 건강수첩 통합
    - (2) **핏펫**(100만+ 다운로드): 건강관리/쇼핑 중심 → 한계: 커뮤니티/매칭 약함 → **밍그르르**: 커뮤니티 + 신뢰도 시스템
    - (3) **반려생활**(10만+ 다운로드): 반려동물 여행/커뮤니티 중심 → 한계: 여행 특화, 매칭/거래/건강수첩 부재 → **밍그르르**: 6대 기능 통합, 일상 전반 커버
    - (4) **펫프렌즈**(200만+ 다운로드): 반려동물 쇼핑몰 1위 → 한계: 커뮤니티/매칭 부재, 신규 판매 중심 → **밍그르르**: 커뮤니티 + 중고거래/나눔 + 신뢰도 시스템
    - (5) **당근마켓**(3,000만+ 다운로드): 중고거래 중심 → 한계: 반려 특화 아님 → **밍그르르**: 반려용품 전문 + 꼬순내 지수

  - 초기 진입 시장 선정 근거:
    - 경기도 수도권을 초기 진입 시장으로 선정
    - 반려동물 등록 수 1위 광역자치단체: 약 145만 마리 (2024, 농림축산식품부)
    - MZ세대 1인 가구 밀집 지역: 성남, 수원, 용인 등
    - 위치 기반 서비스 특성상 사용자 밀도가 핵심
    - 수도권 집중 전략으로 초기 네트워크 효과를 극대화한 후 전국 확장 계획

◦ **타겟 설정**

  - **1차 타겟 (핵심)**: 수도권 거주 2030 MZ세대 1인 가구 반려견 보호자
    - 페인포인트: 반려동물 사회화 기회 부족, 건강관리 정보 부재, 신뢰할 수 있는 커뮤니티 부재
    - 특성: 디지털 네이티브, 앱 기반 서비스 선호, SNS 공유 활발
  
  - **2차 타겟 (확장)**: 전국 2040 반려동물 보호자 (다견 가구 포함)
    - 페인포인트: 용품 비용 부담, 체계적 건강관리 필요
    - 특성: 커뮤니티 참여 의지 높음, 중고거래/나눔 수요 큼

## 2. 실현가능성(Solution)

### 2-1. 기술개발 역량 및 기술개발(고도화) 가능성

◦ **기술개발 역량**

  - 현재 개발 단계: MVP 완성 (시제품 단계)
    - 전체 코드 규모: 222개 파일, 87,617 LOC (✅ 완료)
    - 구현 완료 기능: 반려동물 데이팅(8요소 복합 궁합 매칭), 산책 GPS 추적(실시간 경로, 발자국), 중고거래/나눔(7개 카테고리), 건강수첩(12개 카테고리), 교배 매칭(혈통서 인증), 소모임(6종), 실시간 채팅, 꼬순내 지수(5개 영역 100점), 푸시 알림(FCM)
    - 진행 중: UI/UX 고도화(디자인 개선 및 사용성 테스트 필요)
    - 예정: 앱스토어 정식 출시(실사용 테스트 후)

  - 핵심 기술 요소 및 아키텍처:
    - **프론트엔드**: Flutter 3.10+ (Dart) – iOS/Android 동시 개발로 개발비 50% 절감
    - **백엔드**: Firebase 서버리스 아키텍처 – 초기 서버 비용 최소화, 자동 스케일링 (Auth, Firestore, Storage, Messaging, Functions, Remote Config)
    - **상태관리**: Riverpod 2.x (최신 리액티브 상태관리)
    - **지도/위치**: 카카오맵 SDK + GeoFlutterFire (위치 기반 GeoHash 쿼리)

### 2-2. 경쟁력 확보 방안

◦ **핵심 경쟁력 요소**

  1. **8요소 복합 궁합 매칭 알고리즘**: 8가지 요소(체형, 성격, 거리, 신뢰도, 인기도, 활성도, 나이, 품종)를 데이터 기반으로 복합 분석하는 과학적 매칭 시스템. 50개 반려동물 특성(PetTrait)을 기반으로 성격 보완/충돌까지 분석하는 것은 국내 반려동물 앱 중 유일.

  2. **꼬순내 지수 (신뢰도 시스템)**: 평판(40점) + 활동(20점) + 신뢰(20점) + 커뮤니티(10점) + 활성도(10점) - 감점(최대 15점)으로 구성된 100점 만점 신뢰 평가. 당근마켓의 '매너온도'를 반려동물 생태계에 맞게 고도화한 독자적 시스템.

  3. **6대 기능 통합 플랫폼**: 기존 앱들이 1~2개 기능에 집중하는 반면, 데이팅·산책·거래·건강·교배·소모임을 하나의 앱에서 제공. 사용자 데이터가 통합되어 더 정밀한 매칭과 개인화 가능.

◦ **경쟁사 대비 차별화 요약**

  - 밍그르르만의 차별화 기능:
    - 데이터 기반 매칭 알고리즘: 8요소 복합 궁합 분석 (경쟁사 중 유일)
    - 보호자 신뢰도 시스템: 꼬순내 지수 5개 영역 100점 (경쟁사 중 유일)
    - 교배 매칭: 혈통서 인증 기반 (경쟁사 중 유일)
    - 6대 기능 통합: 데이팅+산책+거래+건강+교배+소모임 (경쟁사 대비 가장 넓은 커버리지)
  - 경쟁사 비교:
    - 펫피: 산책/커뮤니티 중심, 매칭/거래/건강수첩 없음
    - 핏펫: 건강관리/쇼핑 중심, 매칭/신뢰도 시스템 없음
    - 펫프렌즈: 쇼핑몰 중심, 커뮤니티/매칭 부재, 신규 판매 중심

◦ **진입장벽 및 방어전략**

  - (1) **데이터 축적 장벽**: 사용자 활동 데이터(매칭, 산책, 거래, 건강기록)가 쌓일수록 매칭 정확도와 꼬순내 지수의 신뢰성이 향상 → 후발 주자 진입 어려움
  - (2) **네트워크 효과**: 반려동물 커뮤니티 특성상 사용자가 많을수록 매칭·거래·소모임의 가치 증가
  - (3) **통합 생태계 락인**: 건강수첩 데이터, 꼬순내 지수, 매칭 이력 등이 축적되면 타 앱 전환 비용 증가

◦ **고객 확보/유지 전략**

  - **확보**: 수도권 반려동물 카페/공원 오프라인 이벤트, 인스타그램/유튜브 반려동물 인플루언서 협업
  - **유지**: 꼬순내 지수 등급 시스템(빅뱅·화산·뜨끈·솔솔·쑥쑥)으로 게이미피케이션, 건강수첩 알림으로 일상적 재방문 유도


### 2-3. 기술우위 수준

◦ **기술우위 근거**

  1. **8요소 복합 궁합 매칭 알고리즘 (MatchingService)**
     - 8개 카테고리 가중치 시스템: 체형(20%) + 성격(20%) + 거리(15%) + 신뢰도(15%) + 인기도(10%) + 활성도(10%) + 나이(5%) + 품종(5%)
     - 50개 반려동물 특성(PetTrait) 기반 성격 분석: 시너지 특성 쌍, 충돌 특성 쌍 자동 감지
     - 부익부 방지 메커니즘: 신규 가입자 30일 부스트, 일평균 좋아요 기준 상대적 인기도 산출
     - 다양성 확보: 상위 30개 후보 중 랜덤 셔플로 15개 추천 → 매번 다른 추천 결과 제공

  2. **꼬순내 지수 (KkosunnaeService) – 하이브리드 평판 시스템**
     - 원점수(절대 평가, 0~100) + 등급(상대 평가, 백분위 기반) 이중 구조
     - 평가 가중치: 인증 사용자 평가 1.2배, 고신뢰 사용자(70점+) 평가 1.1배, 최근 30일 평가 1.1배 (최대 1.45배)
     - 등급 변동 시 자동 알림 발송
     - 등급 구간 동적 조정: 전체 유저 분포 분석 후 주기적 업데이트

  3. **실시간 산책 추적 시스템**
     - 10m 이동마다 GPS 좌표 자동 저장 + Firebase 실시간 동기화
     - 발자국 기능: 특정 위치에 마킹하여 산책 경험 기록
     - 칼로리·거리·시간 자동 계산
     - 200m 안전구역 기능: 집 반경 내 위치 보호

◦ **기술 차별성의 핵심 원인**

  - (1) **알고리즘**: 반려동물 특성을 반영한 독자적 매칭 로직 (품종 그룹핑, 에너지 레벨 매칭, 생애단계 분류 등). 단순 필터링이 아닌 복합 점수 산출 방식.
  - (2) **데이터 설계**: 12개 Firestore 컬렉션, 복합 인덱스 설계로 대규모 실시간 쿼리 최적화
  - (3) **운영 프로세스**: Cloud Functions 기반 자동화 배치 (회원탈퇴 30일 후 물리삭제, 거래 기록 익명화 보관, 만료 평가 자동 공개)

◦ **재현성·확장성·안정성**

  - (1) **확장성**: Firebase 서버리스 아키텍처로 사용자 증가 시 자동 스케일링. Firestore 오프라인 지속성으로 네트워크 불안정 시에도 앱 동작 보장.
  - (2) **안정성**: 네트워크 상태 실시간 모니터링(NetworkStatusBanner), 에러 핸들링 통합(ErrorHandler), 구조적 로깅(AppLogger)
  - (3) **유지보수**: Feature-First 아키텍처로 기능별 독립적 수정 가능, Mingrr 접두사 컴포넌트 체계로 UI 일관성 유지

◦ **기술 고도화 로드맵**

  - v1.0 (MVP, 현재): 6대 핵심 기능 구현 완료(90% 이상) → 기능 정상 동작
  - v1.5 (개선, 협약 3개월): UI/UX 개선, 성능 최적화 → 앱 로딩 2초 이내
  - v2.0 (정식 출시, 협약 5~6개월): 앱스토어 정식 출시 → 다운로드 500건
  - v2.1 (안정화, 협약 6~8개월): 사용자 피드백 반영, 버그 수정 → MAU 1,000명
  - v3.0 (확장, 협약 이후): 전국 확장, 프리미엄 기능 → MAU 10,000명

    - (5) 리텐션 → 유료: 프리미엄 전환 (목표 5%) → KPI: 유료 전환율

### 3-3. 반려산업 발전 기여 및 사회문제 해결, 가치창출 계획

◦ **반려산업 발전 기여**

  1. **반려동물 사회화 촉진**: 데이터 기반 궁합 매칭으로 성격·체형이 맞는 반려동물 친구를 찾아줌으로써 반려동물의 사회성 발달 지원. 잘못된 만남으로 인한 공격성·스트레스 예방에 기여.

  2. **보호자 양육 수준 향상**: 12개 카테고리 건강수첩으로 체계적인 반려동물 건강관리 문화 확산. 예방접종 알림, 체중 변화 추적 등으로 반려동물 복지 수준 향상.

  3. **반려용품 재순환 경제**: 중고거래/나눔 기능으로 반려용품의 재사용을 촉진하여 자원 낭비 감소 및 양육 비용 절감.

  4. **반려동물 산업 데이터 축적**: 반려동물 특성, 건강 기록, 양육 패턴 등 유의미한 데이터를 축적하여 반려동물 산업 발전을 위한 기초 자료 제공 가능.

◦ **사회문제 해결**

  1. **1인 가구 반려인 고립 해소**: 소모임, 산책 친구 찾기 기능으로 같은 지역 반려인 간 커뮤니티 형성. 사회적 교류 기회 제공으로 1인 가구 외로움 해소.

  2. **유기동물 예방**: 체계적 건강관리와 커뮤니티 지원으로 보호자의 책임감 강화. 양육 포기 방지에 기여.

  3. **안전한 거래 환경**: 꼬순내 지수 기반 신뢰 시스템으로 중고거래 사기, 노쇼 등 사회적 비용 감소.

  4. **지역 경제 활성화**: 동물병원, 펫샵, 반려동물 카페 등 지역 반려동물 관련 소상공인과의 제휴로 지역 경제 활성화 기여.

◦ **가치창출 계획**

  - (1) 반려동물 보호자 간 **신뢰 기반 커뮤니티** 문화 정착
  - (2) 반려동물 양육의 **사회적 인프라** 구축 (건강관리, 교류, 정보 공유)
  - (3) 경기도 반려동물 산업 생태계 내 **ICT 융합 플랫폼** 선도 사례 창출
