## 🔔 필요한 푸시 알림 목록

### 1. 소모임 일정 알림 (우선순위: 높음)

| 알림 유형 | 트리거 시점 | 수신자 | 내용 예시 |
|----------|------------|--------|----------|
| 일정 생성 알림 | 새 일정 등록 시 | 소모임 멤버 전체 | "🗓️ [소모임명]에 새 일정이 등록되었어요" |
| 일정 시작 1일 전 | 일정 시작 24시간 전 | 참여자 | "⏰ 내일 [일정명] 일정이 있어요" |
| 일정 시작 1시간 전 | 일정 시작 1시간 전 | 참여자 | "⏰ 1시간 후 [일정명] 일정이 시작돼요" |
| 일정 변경 알림 | 일정 수정 시 | 참여자 | "📝 [일정명] 일정이 변경되었어요" |
| 일정 취소 알림 | 일정 삭제 시 | 참여자 | "❌ [일정명] 일정이 취소되었어요" |

### 2. 신청/수락 알림 (우선순위: 높음)

| 신청 수락 | 상대방 수락 시 | 발신자 | "🎉 [이름]님이 신청을 수락했어요" |
| 신청 거절 | 상대방 거절 시 | 발신자 | "[이름]님이 신청에 응답했어요" |
| 신청 만료 예정 | 만료 1일 전 | 수신자 | "⏳ [이름]님의 신청이 내일 만료돼요" |

## 🛠️ 기술 구현 사항

### 1. Firebase Cloud Messaging (FCM) 설정

```dart
// 필요한 패키지
// firebase_messaging: ^15.x.x (이미 설치됨)

// 구현 필요 사항
// 1. FCM 토큰 관리
// 2. 토큰 갱신 처리
// 3. 포그라운드/백그라운드 알림 처리
```

### 2. 서버 사이드 (Cloud Functions)

```javascript
// 필요한 Cloud Functions
// 1. onScheduleCreate - 일정 생성 시 알림
// 2. onRequestCreate - 신청 생성 시 알림
// 3. onMessageCreate - 메시지 생성 시 알림
// 4. scheduledNotifications - 예약 알림 (일정 리마인더 등)
```

### 3. 사용자 설정

```dart
// users 컬렉션에 추가할 필드
// - fcmToken: string (FCM 토큰)
// - notificationSettings: map (알림 설정)
//   - chat: boolean (채팅 알림)
//   - request: boolean (신청 알림)
//   - schedule: boolean (일정 알림)
//   - community: boolean (커뮤니티 알림)
//   - marketing: boolean (마케팅 알림)
```
